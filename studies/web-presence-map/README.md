# RaidGuild Web Presence Map

Editable source for the interactive constellation published at `/web-presence-map/`.

## Build

```sh
node studies/web-presence-map/build.mjs
```

The build copies `index.html`, `styles.css`, and `app.js` into
`public/web-presence-map/`. Keep those generated files in sync with this source.

## Link evidence

- The Venture Beyond WIP front door was verified at
  `https://raidguild-website-redesign-production.up.railway.app/` on 2026-09-12.
- RaidGuild AI was verified at `https://raidguild.ai/` on 2026-09-12.
- The specified WIP `/onchain` route returned 404 on 2026-09-12, so it is shown
  without a link.
- Placement and Forge remain non-navigable WIP/planned nodes because no approved
  repository evidence confirmed their destinations for this map.

The artwork is CSS/SVG-native and does not reproduce or approximate a RaidGuild
brand mark. The central constellation hub is an abstract navigational symbol.
