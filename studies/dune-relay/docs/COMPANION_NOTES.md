# Companion notes

After a character's required introduction, talking to them again opens one optional, short note. The notes mix current chapter level advice, fictional character observations, and paraphrased RaidGuild Handbook facts. Closing a note returns to the path; it does not start a level, change progress, spend coins, or save conversation history. Notes rotate only for the current browser session. A completed chapter offers facts and observations, without stale level advice.

The Handbook facts were checked against the public Handbook on **November 20, 2026**. They are curated paraphrases, not quotations or claims that the fictional companions are real Guild members. The game bundles these lines so conversation works offline and no live Handbook request is needed. Gameplay tips describe this game's mechanics and are not Handbook claims.

Sources used:

- [What is RaidGuild?](https://handbook.raidguild.org/docs/overview/what-is-raidguild) — open source value.
- [Skills & Roles](https://handbook.raidguild.org/docs/membership/skills-roles) — Tavern Keepers, Wizards, Paladins, Druids, Rangers.
- [Code of Conduct](https://handbook.raidguild.org/docs/overview/code-of-conduct) — clear communication when issues arise.
- [Intro to Raiding](https://handbook.raidguild.org/docs/raids/intro-to-raiding) — project Raid parties, Clerics, Guild Monks.
- [Join the Guild](https://handbook.raidguild.org/docs/membership/join-the-guild) — Portal profiles and Discord community.
- [PRISM](https://handbook.raidguild.org/docs/agents/prism) — Queen Raida and human judgment.

The source for each Handbook line is also linked from its conversation card. To add new facts, verify them against the current Handbook and keep them short and stable. Run `npm run test:core` for dialogue selection checks and `npm run typecheck` for the game integration.
